# Note lettering

Book inspection and hover notes use **Caveat Medium**, by Pablo Impallari and contributors,
for the author and category annotations. Body copy remains Newsreader.

The Latin WOFF2 is self-hosted at `public/fonts/caveat-medium.latin.woff2`. It is
requested only when a visible note uses the font; no Google Fonts requests run
in visitors' browsers. The font is distributed under the SIL Open Font License
in `caveat-ofl.txt`.

- [Upstream source and license](https://github.com/googlefonts/caveat)
- [Pinned Latin WOFF2](https://fonts.gstatic.com/s/caveat/v23/WnznHAc5bAfYB2QRah7pcpNvOx-pjcB9eIWpYQ.woff2)

The supplied subset is committed and copied by the normal Docker build; it does
not need a network request or font-generation step during deployment.
