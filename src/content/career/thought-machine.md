Thought Machine builds a cloud-native banking platform that some of the world’s largest banks run on. I worked on the Workflows team’s operations dashboard, a React and Go app that lets each bank build its own process pages, and helped design a documentation site generated straight from our API definitions. I also led a few frontend-wide clean-ups, like replacing a home-grown forms library with Redux and Formik.
